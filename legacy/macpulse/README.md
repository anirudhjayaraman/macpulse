# macpulse is now macverdict

This project was renamed to **[macverdict](https://pypi.org/project/macverdict/)**:
"MacPulse" was already the name of another Mac app.

Install the new name instead:

```bash
pipx install macverdict      # or: brew install anirudhjayaraman/tap/macverdict
macverdict setup
```

`macverdict setup` brings your macpulse history across and removes the old background parts.

This final `macpulse` release only installs `macverdict` and keeps a `macpulse` command that
points you to it.

Source: https://github.com/anirudhjayaraman/macverdict
